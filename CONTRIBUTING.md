# Contributing

Thanks for looking. This repository is maintained in the open, and changes are
accepted as pull requests.

1. Open an issue first for anything larger than a typo or a link fix.
2. One logical change per pull request, and say **why** in the body.
3. Keep the existing formatting and style; do not reflow unrelated lines.
4. Do not overstate what a check proves: a passing resource check, a passing
   unit test, and a completed run each prove only their own scope.
5. Never commit secrets, tokens, customer data, or machine-specific paths.

By contributing you agree that your contribution is licensed under the same
license as this repository.
